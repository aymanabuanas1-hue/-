# المحرر الشامل — المرحلة التاسعة

نسخة تثبيت وتحسين فوق المرحلة الثامنة.

## تحسينات المرحلة التاسعة
- حفظ صامت تلقائي عند انتقال التطبيق للخلفية لمنع فقدان آخر تعديل.
- تنظيف اسم الملف عند التصدير وإضافة معرف زمني لمنع الكتابة فوق ملف سابق.
- منع ظهور إطار التحديد داخل ملفات PNG وPDF المصدرة.
- تقييد التكبير والفهرس والخلفية إلى نطاقات آمنة عند الحفظ.
- رفع versionCode إلى 9 وversionName إلى 1.9.0.
- الحفاظ على JSON وUndo/Redo والقوالب والخلفيات والمحرر المتداخل.

## التحقق المطلوب في Android Studio
1. افتح مجلد المشروع.
2. نفذ Gradle Sync.
3. Build > Make Project.
4. شغّل على جهاز Android.
5. اختبر إنشاء/حفظ/إعادة فتح معادلة متداخلة.
6. اختبر PNG وPDF والمشاركة.
7. اختبر دوران الجهاز إن رغبت بإزالة portrait لاحقًا.

لم يتم الادعاء باختبار APK فعلي داخل بيئة الإنشاء الحالية لعدم توفر Android SDK/Gradle التنفيذي فيها.

## البناء من Chrome

راجع `GITHUB_BUILD_GUIDE_AR.md`. يوجد GitHub Actions جاهز في `.github/workflows/build-apk.yml` لبناء APK باستخدام Java 17 وGradle 8.7 وAndroid SDK 35 دون الحاجة إلى Android Studio على جهازك.
